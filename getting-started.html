Getting started

Set it up, on your computer.

Unzip, start Docker, pull the local models, run one script — then connect your own TikTok account.

Creator Stack Combo runs in Docker on your own computer. There is no cloud account to sign up for and no hosted dashboard. Follow the steps below in order.

Before you start

What you need

Have these ready before step 1. Nothing else is required to get the stack running.

The Creator Stack Combo files

The combo download, unzipped on your computer. The steps below assume the unzipped folder is called creator-stack-combo.

Docker Desktop

Docker Desktop installed on your computer, and running before you start the stack.

Ollama

Ollama installed on your computer, for the local models the agent uses for drafting.

Your own TikTok account

The TikTok account you own and want to connect. You will sign in on TikTok’s own pages — the app never asks for your TikTok password.

It runs on macOS, Windows, and Linux, through Docker Desktop. Make sure you have enough disk space for your video and clips.

Install

Seven steps to a running stack

Each step builds on the last. If a step fails, fix that step before moving on.

1
Unzip Creator Stack Combo

Unzip the combo download on your computer, so you have a folder called creator-stack-combo.

2
Make sure Docker Desktop is running

Open Docker Desktop and wait until it reports that it is running. The stack will not start without it.

3
Pull the local models with Ollama

Pull the two models the agent uses:

ollama pull qwen2.5:7b
ollama pull qwen2.5vl:3b

Wait for each pull to finish before continuing.

4
Start the stack

From inside the unzipped folder, run the start script:

cd creator-stack-combo && ./start.sh

The script checks the folders, generates the stack’s own secret keys, and starts the services in order. Wait for it to finish.

5
Open the Observe panel

Open the panel in a browser on the same computer:

http://localhost:8000/observe

It asks for the admin key once, then shows the agent’s status, drafts, and the TikTok connection card.

6
Open the ClipForge dashboard

ClipForge has its own dashboard in a browser on the same computer:

http://localhost:5173

This is where long-form video is turned into vertical clips.

7
Connect TikTok from the Observe panel

In the Observe panel, use “Connect TikTok.” TikTok’s own sign-in page opens — log in there and approve the permissions. The app never sees or stores your TikTok password.

After setup

What happens next

Review drafts first

The agent starts researching trends and drafting on its own schedule. Every draft waits in the approval queue — read the exact wording and clip before deciding anything. Nothing is published from a draft on its own.

Make clips with ClipForge

Use the ClipForge dashboard to cut vertical 9:16 clips from your own long-form video, with captions. Finished clips come back as drafts for the same review step.

Revoke access any time

In TikTok’s settings, under authorized apps, remove Creator Stack Combo at any time. That immediately stops the app from reaching your account. See the Privacy Policy for exactly what is stored and where.

Stuck?

Check that Docker Desktop is running and that the start script finished, then re-open the Observe panel. If you still need help, see Support or email hello@creatorstackcombo.xyz.
