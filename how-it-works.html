How it works

From install to first draft.

Creator Stack Combo runs in Docker on the creator's own computer. There is no cloud account, no hosted dashboard, and no one else's server in the middle.

Setup

Five steps, all on your computer

1

Install it locally

Unzip the stack, start Docker Desktop, and run the start script. It runs on your own computer.

2

Connect TikTok

Use “Connect TikTok” in the Observe panel and approve access on TikTok’s own sign-in page.

3

Draft, clip & review

Ideas and clips land as drafts. You read, edit, and approve the exact content before anything goes further.

The short version above is the whole flow. The five detailed steps below spell out each part.

1
Install Docker and the stack

Install Docker Desktop, unzip Creator Stack Combo, and run the included start script. It checks the folders, generates the stack's own secret keys, and starts the services in order.

2
Start the local model (optional, recommended)

Install Ollama and pull the models the agent uses for drafting. Without a local model the agent still works, but drafts fall back to simpler built-in templates.

3
Open the Observe panel

Open the panel in a browser on the same computer. It asks for the admin key once, then shows the agent's status, drafts, and the TikTok connection card.

4
Connect TikTok with Login Kit

Use “Connect TikTok” in the panel. TikTok's own sign-in page opens, the creator logs in there and approves the permissions. The app never sees or stores the TikTok password.

5
Review drafts, make clips

The agent starts researching trends and drafting on its own schedule. The creator reviews drafts in the approval queue and uses ClipForge to cut clips from long-form video.

Where your data lives

On your computer, not ours

There is no Creator Stack Combo cloud. Drafts, clips, tokens, and logs live in folders on the creator's own machine.

TikTok tokens
Encrypted and stored locally only. They are never sent to any Creator Stack Combo server, because there isn't one.
Drafts & clips
Stored on the creator's computer. A draft is only a local file until the creator decides what to do with it.
Sign-in
Happens only on TikTok's own pages, through Login Kit. The app never asks for a TikTok password.
Revoking access
Any time, in TikTok's settings, under authorized apps — or by deleting the local token store. Both are described in the Privacy Policy.

What the app will not do

These limits are part of the product, and they are the same limits stated in the Terms of Service.

It will not

  • Publish anything without the creator reviewing and approving the exact draft
  • Like, follow, comment, or send messages on its own
  • Buy followers, fake engagement, or run engagement pods
  • Scrape private profiles, direct messages, or sensitive personal data

It will

  • Research trends and draft content locally
  • Cut vertical clips from the creator's own video
  • Keep everything in an approval queue for the creator
  • Use TikTok's official APIs only, with the permissions the creator approved
